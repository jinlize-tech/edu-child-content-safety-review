## 2. 用户、痛点与目标

- 用户：教研、内容审核、市场、课程产品负责人
- 痛点：面向儿童的内容可能包含不适宜恐惧、危险模仿、消费诱导、刻板印象、隐私暴露或超龄知识。
- 目标：按年龄段检查课程、故事、题目、活动和营销素材的安全、适龄、公平与商业边界。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `content_text` | 待审儿童内容 | string | 是 |
| `target_age` | 目标年龄 | string | 是 |
| `context` | 使用场景 | string | 是 |
| `teacher_supervision` | 是否教师陪同 | boolean | 是 |
| `media_description` | 图片视频或实验描述 | string | 否 |
| `commercial_purpose` | 商业目的 | boolean | 是 |
| `existing_review_rules` | 现有审核规则 | array | 否 |

## 4. 工作流

1. 确认年龄与场景
2. 逐段识别风险
3. 分类严重度
4. 说明原因
5. 提出更安全替代表达
6. 人工复核
7. 发布建议

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点内容原文、目标年龄、使用场景、是否教师陪同、图片/视频描述、商业目的、已有审核规则，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕按年龄段检查课程、故事、题目、活动和营销素材的安全、适龄、公平与商业边界。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认年龄与场景 → 逐段识别风险 → 分类严重度 → 说明原因 → 提出更安全替代表达 → 人工复核 → 发布建议设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由儿童教育/安全专业人员和课程负责人复核儿童适龄、危险模仿、商业诱导与发布决定。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `儿童内容审核表`
- `风险段`
- `发布结论`

## 7. 差异化与排重

- 与现有产品：招生宣传合规聚焦商业宣传；本产品审查儿童接触的全部内容安全和适龄性。
- 排重检查：部分重叠；可用于广告/课件，但风险标准涵盖儿童安全、公平、隐私和商业诱导。
- 独立理由：任意儿童内容均可独立审查，无需课程或营销产品。

## 8. 安全与人工门禁

- 复核角色：儿童教育/安全专业人员和课程负责人
- 复核范围：儿童适龄、危险模仿、商业诱导与发布决定
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。

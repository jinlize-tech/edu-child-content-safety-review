# 儿童内容适龄与安全审查领域指南

## 业务问题

面向儿童的内容可能包含不适宜恐惧、危险模仿、消费诱导、刻板印象、隐私暴露或超龄知识。

## 产品解决方案

按年龄段检查课程、故事、题目、活动和营销素材的安全、适龄、公平与商业边界。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `content_text` | 待审儿童内容 | 是 | 课程、故事、活动或广告文案 |
| `target_age` | 目标年龄 | 是 | 明确最小和最大年龄 |
| `context` | 使用场景 | 是 | 课堂、家庭、线上或线下 |
| `teacher_supervision` | 是否教师陪同 | 是 | 决定风险阈值 |
| `media_description` | 图片视频或实验描述 | 否 | 无原始媒体时可用文字描述 |
| `commercial_purpose` | 商业目的 | 是 | 是否用于招生或销售 |
| `existing_review_rules` | 现有审核规则 | 否 | 机构已有标准 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

儿童教育/安全专业人员和课程负责人应确认：儿童适龄、危险模仿、商业诱导与发布决定。未经确认的内容只能作为草案。

## 主要风险

适龄判断需儿童教育/保护专业人员复核；不同文化家庭有差异；不得过度删减必要知识但需降低风险。
